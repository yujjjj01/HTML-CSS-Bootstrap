04. 從靜態讀取到價值互聯網的演進歷程

理解網際網路三十年的架構轉移，見證數位所有權的真正誕生。

1990 - 2004
READ-ONLY 唯讀時代
核心角色 入口網站與站長 代表平台 Yahoo, GeoCities

Web 1.0 資訊目錄

去中心化但靜態的撥接時代。用戶扮演純粹的資訊接收者，內容由少數站長發布，缺乏互動性與個人化體驗。

  • 靜態 HTML 與伺服器目錄
  • 開放式標準協定（HTTP、SMTP）
  • 無使用者帳號體系與動態狀態
2004 - 至今
READ & WRITE 互動時代
核心角色 平台巨頭與廣告商 代表平台 Google, Meta, AWS

Web 2.0 平台經濟

社交網路與雲端計算崛起。使用者可自由創作內容，但資料與身分被封閉在科技巨頭的資料庫中，形成了「資料即石油」的演算法壟斷。

  • 動態互動與社群影音平台
  • 雲端伺服器與行動 App 普及
  • 個資商業變現與單點審查風險
2020 - 未來
READ, WRITE & OWN 數位主權
核心角色 主權個人與開源社群 代表技術 以太坊, IPFS, 零知識證明

Web 3.0 價值協定網

以密碼學與分散式帳本為基石。個人直接掌握私鑰與資產主權，無須許可即可跨平台調用合約，實現抗審查、點對點的價值轉移。

  • 自主主權身分（DID）與私鑰簽名
  • 開源智能合約與不可竄改帳本
  • 可組合的去中心化金融與治理體系

私鑰即身分 (Self-Sovereign)

沒有任何機構能凍結或重設您的身分。公鑰向世界公開驗證，私鑰永遠由個人離線安全守護。

09. DAO：開源社群的自動化治理機制

沒有董事會、沒有官僚層級，由智能合約與代幣投票驅動的協作模式。

01
社群提案發起 (CIP Proposal)

任何社群成員均可在論壇提交治理改善提案，經歷為期 7 天的公開辯論與共識凝聚。

02
鏈上密碼學投票 (Snapshot / On-Chain)

根據持有治理代幣的權重發起無 Gas 簽名投票，選票結果寫入區塊鏈，無法被任何個人篡改。

03
合約自動觸發執行 (Timelock Execution)

通過門檻的提案經由時間鎖 (Timelock) 保護期後，智能合約自動自金庫撥款或更新合約參數。
